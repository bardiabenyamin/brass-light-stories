# Proof-of-Work Tests

Status: **BLOCKED: needs separate spend approval**

The prompt book recommends a 30–60 second proof-of-work before scaling, to measure:

1. Character consistency across angles and shots
2. Animation quality (motion, morphing, face drift)
3. Voice quality and commercial-use rights
4. **Actual credit cost** per keyframe, per clip, and per audio minute, plus the retry rate

## Recommended timing

Run it after the roadmap is approved **and** after Prompts 02–03 have produced, as text, the character bible and
visual style. Without them the test would show what the tool can do, but not whether this series' characters and
style hold up.

## Proposed shape (`PROPOSED — NEEDS APPROVAL`; filled in after Prompt 03)

- 1 core character, 1 core location
- About 3 keyframes, then 4–6 clips of 3–8 s each
- About 3 short voice lines for one character
- Rough assembly in Remotion (local, no credit cost)
- Credit cap: **owner to set**. Claude quotes an estimate before asking for approval.

Test outputs go in `04-TESTS/POW-001/`. Each test is logged in `COST-LOG.md`.
