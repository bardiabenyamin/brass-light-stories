# Props — *The Early Shelf*, Season 1

Status: **LOCKED v1 — Prompt 03, 2026-11-09.** No prop images exist yet. The reference prompts are in
`../06-EPISODES/EPISODE-001/prompts.md` § "Prop reference batch" (PR-xx), built from the blocks below.

**Rules:**
- **Story props are about 10% oversized**, so they read at 1080p.
- **One hero prop per insert.**
- **No text, numerals, logos, or monograms** on any prop. The clock and watch dials use baton markers only.
- **Reserved colors:** mustard yellow belongs to the umbrella only. Red belongs to memory and love props only (the
  lantern, toy train, mitten, Ida's cord, and her thread).
- **Glows:** the amber arrival glow is composited in the edit (`visual-style.md` §6), so prop references are rendered
  unlit. The exception is memory-objects, whose pale-gold glow is their permanent look.
- State changes are tracked in `../06-EPISODES/EPISODE-001/continuity.md` ("Character-held props").
